# Profil Gampong Baro — Kecamatan Meuraxa

Website profil statis dengan tampilan baru berbasis foto latar, tanpa database, backend, atau proses build.

## Menjalankan
Ekstrak ZIP, lalu buka `index.html` di browser. Foto latar, lambang kota, font, dan peta memerlukan koneksi internet.

## Tampilan dan isi
- Hero utama memakai foto lokal dari `assets/image/` dengan overlay gelap.
- Profil berisi visi dan misi gampong.
- Tabel identitas dan data gampong (termasuk nama Keuchik Darwis Ilyas dan alamat kantor).
- Informasi Masjid Baitul A’la disebut terpisah sebagai masjid yang tercatat di Gampong Baro.
- Luas wilayah 0,58 km² (58,20 ha; data dasar BPS tahun 2020).
- Jumlah penduduk 2.034 jiwa (data 2024, publikasi BPS Kecamatan Meuraxa Dalam Angka 2025).
- Informasi Polindes dan katalog peta wilayah.
- Peta lokasi Google Maps.

## Sumber
- Foto hero: dokumentasi lokal Gampong Baro (`assets/image/`).
- BPS Kota Banda Aceh, *Kecamatan Meuraxa Dalam Angka 2025* (data penduduk 2024).
- BPS Kota Banda Aceh, *Kecamatan Meuraxa Dalam Angka 2021* (luas wilayah 58,20 ha; data dasar 2020).
- Dinas Kesehatan Kota Banda Aceh, daftar Polindes.
- UPTB GIS Kota Banda Aceh, katalog “Gampong Baro Map”.
- Daftar Masjid se-Kota Banda Aceh 2025 mencantumkan Masjid Baitul 'Ala di Gampong Baro.

## Catatan
Foto latar memakai dokumentasi lokal dari `assets/image/` sebagai foto suasana. Ganti nama file di `styles.css` bila ingin memakai foto lain. Luas dan jumlah penduduk memakai tahun data sebagaimana tertulis; tidak dianggap sebagai data terkini.
